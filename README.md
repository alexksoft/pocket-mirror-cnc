# Кишенькове дзеркало з дерева — 3D модель для ЧПУ

Кругле кишенькове дзеркало з двох дерев'яних половинок (горіх), з'єднаних латунним шарніром. Закривається на неодимові магніти.

## Розміри

| Параметр | Значення |
|----------|----------|
| Зовнішній діаметр | 70 мм |
| Загальна висота (закрите) | 16 мм |
| Висота половинки | 8 мм |
| Товщина стінки | 4 мм |
| Фаска (fillet) | R2 мм |
| Виїмка під дзеркало | ∅58 × 2 мм |
| Виїмка під фото | ∅58 × 2 мм |
| Шарнір | латунний ∅5 × 20 мм |
| Магніти | неодим ∅6 × 2.5 мм |

## Файли

| Файл | Опис |
|------|------|
| `pocket_mirror.scad` | Параметрична модель OpenSCAD (повна, з шарніром і магнітами) |
| `generate_stl.py` | Python генератор STL (без залежностей) |
| `pocket_mirror_top.stl` | STL кришки (з виїмкою під дзеркало) |
| `pocket_mirror_bottom.stl` | STL основи (з виїмкою під фото) |
| `pocket_mirror_assembly.stl` | STL збірки для візуалізації |
| `gcode_notes.md` | Нотатки для CAM / G-code |

## Як користуватись

### Варіант 1: OpenSCAD
1. Встановіть [OpenSCAD](https://openscad.org/)
2. Відкрийте `pocket_mirror.scad`
3. Змініть параметри на початку файлу якщо потрібно
4. Рендер → Export STL

### Варіант 2: Python STL генератор
```bash
python3 generate_stl.py
```
Створить 3 STL файли в поточній директорії.

### Варіант 3: Готові STL
Просто імпортуйте `pocket_mirror_top.stl` та `pocket_mirror_bottom.stl` у ваше CAM ПЗ.

## Обробка на ЧПУ

### Заготовка
Кожна половинка: **74 × 74 × 12 мм** (горіх, дуб, бук)

### Інструмент
- Кінцева фреза ∅6 мм — контур, кишені
- Сферична фреза ∅4 мм (R2) — фаски
- Свердло ∅6 мм — отвори під магніти
- Свердло ∅2.5 мм — отвір під штифт шарніра

### Послідовність
1. **Сторона А** (зовнішня): зовнішній контур + фаски R2
2. **Сторона Б** (внутрішня): кишеня ∅58×3мм + паз шарніра 6×4×20мм + отвори

### Режими різання (горіх)
- Оберти: 18000–22000 об/хв
- Подача: 1500–2000 мм/хв
- Глибина за прохід: 2 мм (чорнова), 0.3 мм (чистова)
- Stepover (чистова): 10–15% діаметра фрези

## Матеріали для збірки

- Деревина горіх — 2 заготовки 74×74×12 мм
- Латунний бочковий шарнір ∅5 × 20 мм
- Неодимові магніти ∅6 × 2 мм N35 — 2 шт
- Дзеркало кругле ∅57.5 мм, товщина 1.5–2 мм
- Оргскло/акрил ∅57.5 мм (під фото)
- Епоксидний або UV-клей

## Фінішна обробка

1. Шліфування: 120 → 180 → 240 → 320 → 400 грит
2. Підняття ворсу: змочити, висушити, шліфувати 400
3. Покриття: данське масло (2-3 шари) або тунгове масло
4. Полірування воском (карнауба)

## Збірка

1. Вклеїти магніти (перевірити полярність!)
2. Встановити шарнір + штифт
3. Вклеїти дзеркало (UV або силікон)
4. Вкласти фото під акрил
